# ACMC 2016 (Sonic Environments): archived sources

Copies of web pages that the 2016 proceedings entries rely on, kept here in case
the originals disappear (issue #29). Files are stored byte for byte as fetched,
under their original host and path.

**`print/all`** is Sched's print view of the whole NIME 2016 schedule, which
included Sonic Environments (ACMC 2016, 10–11 July 2016, Queensland
Conservatorium). Sonic Environments sessions are marked "S" (sessions) and "C"
(papers). It gives each session's day, time, room, moderators, presenters and
performers, with the abstracts and program notes as submitted to Sched. The
days, times and performers of the 2016 creative works come from it.

The Wayback Machine had no capture of this page when it was fetched, and
attempts to save it there on 1 November 2026 failed (HTTP 523, then rate
limited). The page loads jQuery and Selectize from cdnjs; everything else is
inline.
