A thirst for data in all its forms. Streaming digits, numbers, patterns, sounds. The audio is constructed from raw data sources such as images, image and sound manipulation binaries a browser binaries etc. The images are produced using the composers own sound->image translation software as well as Akira Rabelais’ Argeiphontes Lyre 2.0 for the background numbers.
