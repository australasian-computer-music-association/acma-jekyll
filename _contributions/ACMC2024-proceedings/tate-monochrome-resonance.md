Monochrome Resonance delves into the interplay between audio and visual elements by utilising custom-built Lo-Fi audio samplers and modified CD players. This project explores how sound and visual stimuli interact through tactile and physical inputs, extending the author’s ongoing work with repurposed consumer electronics and obsolete media to create new musical experiences. At the core of this piece is the use of a Fast Fourier Transform (FFT) algorithm programmed on an Arduino (Atmega 328). This algorithm converts audio signals into bar-graph-like visual patterns that represent different frequency bands. These patterns are then transmitted via composite signal to a CRT monitor, providing a real-time visual representation of the audio.The interaction between sound and visual output is further enhanced by light sensors attached to the CRT screen. These sensors detect changes in the visual patterns of frequency and amplitude, triggering a set of switches connected to the RAM (Random Access Memory) buffers of circuit-bent portable CD players and a custom-designed ISD1820 sampling device. Together with various handmade sound-making and processing devices, this setup creates a recursive audio-visual feedback loop.The result is a generative system that continuously evolves, with audio influencing and transforming the visual output, and vice versa. This integration of sound and visual elements creates an engaging experience that blurs the lines between auditory and visual art forms. The work explores the creative possibilities of outdated technology and the utilisation of simple microcontrollers, demonstrating how repurposed electronics can repurpose media and connect sound and image in a generative environment.
