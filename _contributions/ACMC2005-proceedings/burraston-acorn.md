Acorn was created using 2D multi state Cellular Automata programmed in BBC BASIC on an Acorn RISC machine. The sound output was processed by an analogue modular synthesizer (Roland System 100M & Doepfer A100). The final production and mixing was made by Australian electronic music legend Garry Bradbury (ex Severed Heads)
