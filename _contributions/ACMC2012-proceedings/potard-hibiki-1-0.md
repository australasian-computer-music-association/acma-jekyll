Hibiki 1.0 is part an interactive sound installation and part a musical piece. Hibiki 1.0 will implement real-time sonification of data streams obtained from the internet. Such data may be collected using specialised online tools such as Nimbits which makes available hundreds of sensor data streams. The focus of Hibiki is to sonify environmental data and the impact of human consumption of resources; this represents a sonification layer. Other sonification layers may also be implemented, for example: Internet traffic, the weather, stock exchange data etc.

Another important aspect of Hibiki is interactivity: using their web-enabled mobile phones, the public will be able to modify parameters of the sonification mapping and the current sonification layer. We implement interactivity using an HTML5 web page and custom server-side software which makes our technique cross-platform and no native app installation is required. Hibiki will be implemented as a permanent sound installation in the Nishi building which is a modern and 6 green star rated building complex currently being developed in Canberra. Hibiki was commissioned as an experiment in architectural audio, data sonification and user interactivity.

Hibiki will be shown for the first time to the public at ACMC 2012.
