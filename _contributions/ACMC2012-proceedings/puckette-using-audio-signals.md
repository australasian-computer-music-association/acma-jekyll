The most natural source of control for a real-time computer process is a microphone pointed at a person or instrument. It's easy enough to measure things like pitch, amplitude, or spectral envelope, but then many interesting considerations come up when we try to use these to control a sound-generating process in a computer. For example, how accurately can one or another parameter be controlled by an instrument or voice? How quickly can it change? Can continuously changing values be parsed into yes-or-no events, and with what time lag, time accuracy, and robustness? This workshop will provide an exploration of these issues using some specific examples. We'll use Pd for the demonstrations, although participants can probably work along in Max or Supercollider as they prefer, and should be able to use their own laptops and built-in microphones.
